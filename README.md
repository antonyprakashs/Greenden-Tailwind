🌿 Greenden – Plant Store Website

Greenden is a responsive plant store website built using HTML and Tailwind CSS.
This project focuses on creating a clean UI, responsive layout, and modern design using utility-first CSS.

🚀 Features

🌱 Modern and clean UI design

📱 Fully responsive layout

🎨 Styled using Tailwind CSS

🛍️ Product showcase section

📩 Contact section

🧭 Navigation bar with smooth layout

🛠️ Built With

HTML5

Tailwind CSS

🎯 Purpose of the Project

This project was created to practice:

Tailwind CSS utility classes

Responsive design

Layout structuring

Frontend development fundamentals
